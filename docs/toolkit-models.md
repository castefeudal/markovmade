# MARKOVMADE LAB — модели и границы

Версия новых моделей: `2.0.0`, review источников и численных fixtures: 2026-10-06. Расчёты предназначены для самостоятельного планирования здоровыми взрослыми. Они не устанавливают диагноз, не назначают лечение и не гарантируют результат.

Каталог содержит 24 задачи. Связанные показатели намеренно собраны в один инструмент.

| Направление | Инструмент | Тип и основные границы |
|---|---|---|
| Тело | Состав тела, LBM, FFMI, normalized FFMI, целевой вес | Опубликованные окружностные формулы и арифметика; исходная ошибка BF переходит в производные метрики. Целевой вес предполагает сохранение LBM. |
| Тело | Проекция рекомпозиции | Сценарий заданных изменений FM/FFM, без срока и прогноза роста мышц. |
| Тело | Динамика окружностей | Разница двух замеров; не отделяет ткани, воду и ошибку ленты. |
| Питание | Калории и БЖУ: QUICK, PRO, adaptive | Mifflin / ten Haaf и практическая калибровка по 14–28 дням. Качественные наблюдения имеют приоритет над predictive equation. |
| Питание | Ориентир по белку | Evidence-informed диапазон 1,6–2,2 г/кг для силовых тренировок; верхняя граница не обязательна. |
| Питание | Темп и длительность фазы | Линейный сценарий, не обещание даты; запас 0,8–1,3× выбран для планирования, не статистический интервал. |
| Питание | Переедание и изменение веса | Энергетический эквивалент, TEF и сценарий воды/гликогена; не прогноз фактической прибавки жира. |
| Тренировки | e1RM | Epley / Brzycki; точность зависит от упражнения, техники, RIR и числа повторов. |
| Тренировки | Рабочий вес по %1RM / RIR | %1RM — арифметика; добавление RIR в Epley — отдельная практическая эвристика. |
| Тренировки | Блины | Точный subset-sum доступного симметричного набора, включая случаи, где greedy-подход ошибается. |
| Тренировки | Объём и тоннаж | Точная арифметика; не измеряет тренировочный стимул или качество техники. |
| Тренировки | Прогрессия | Правило двух сессий, диапазона повторов, RIR и небольшого шага; не прогноз силы. |
| Тренировки | Интенсивность кардио | Tanaka HRmax и ориентиры интенсивности; разговорный тест помогает сопоставить оценку с ощущением усилия. |
| Восстановление | Readiness и HRV/RHR baseline | Практическая эвристика самонаблюдения; baseline по 14–28 личным наблюдениям, не медицинский score. |
| Восстановление | Окно сна | Арифметика времени, отдельно от качества сна; субъективная оценка времени бодрствования. |
| Восстановление | Кофеин | Сценарий одной дозы и выбранных half-life 3–7 ч; не индивидуальная фармакокинетика. |
| Восстановление | Сигнал усталости / deload | Практические пороги; не диагноз. Стойкие симптомы и боль относятся к врачу. |
| Прогресс | Тренд, плато, ETA, коррекция калорий | Theil–Sen, moving averages, проверка вероятных выбросов; ETA и пороги — практические правила. Исходные наблюдения не удаляются автоматически. |
| Прогресс | Еженедельный пересмотр | Факт → проверяемый вывод → один эксперимент; не устанавливает причинность. |
| Поведение | Соблюдение плана | Выполнено / запланировано; не психометрическая оценка. |
| Поведение | Аудит препятствий | Приоритет из субъективных оценок времени, среды и сложности. |
| Поведение | Минимально достаточный день | Собственное действие в доступное время; не универсальная норма нагрузки. |
| Поведение | «Если → то» | Опубликованный подход к планированию; не гарантия выполнения. |
| Поведение | Главный рычаг на 7–14 дней | Правило приоритизации; не психологическая диагностика. |

Методика раскрывается рядом с инструментом: тип модели, формула, ограничения, источник, версия и дата review. Результат отделяет цифру, интерпретацию, уверенность, неопределённость, действие и способ повысить точность. «Высокая» в точной арифметике означает правильность вычисления введённых данных, а не достоверность физиологического вывода.

Первичные источники: [Kouri — FFMI](https://pubmed.ncbi.nlm.nih.gov/7496846/), [Mifflin](https://pubmed.ncbi.nlm.nih.gov/2305711/), [Morton — белок](https://pubmed.ncbi.nlm.nih.gov/28698222/), [ACSM — прогрессия](https://pubmed.ncbi.nlm.nih.gov/19204579/), [Tanaka — HRmax](https://pubmed.ncbi.nlm.nih.gov/11153730/), [HHS — интенсивность](https://www.cdc.gov/physical-activity/media/pdfs/Physical_Activity_Guidelines_2nd_edition.pdf), [AASM — сон](https://aasm.org/advocacy/position-statements/adult-sleep-duration-health-advisory/), [Drake — кофеин](https://pmc.ncbi.nlm.nih.gov/articles/PMC3805807/), [Gollwitzer / Sheeran — implementation intentions](https://doi.org/10.1016/S0065-2601(06)38002-1).

Все данные остаются на устройстве. JSON включает профиль, результаты, историю и ежедневные наблюдения; импорт новых инструментов проверяет входные данные и пересчитывает результат. Текстовый экспорт создаётся по явному действию. Перед передачей заявки или результата в мессенджер показывается текст и отдельная ссылка продолжения.

EREPS 2019, МИИН 2022 и ICA 2026 указаны по сведениям владельца в задании. В рабочей копии нет отдельных файлов сертификатов; номера документов, медицинские титулы и schema credentials не добавлены. История содержит только авторский путь; сценарии не объявлены клиентскими кейсами.
