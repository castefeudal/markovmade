# MARKOVLAB — единая методология

Панель «MARKOVMADE · Методология» содержит девять основных разделов. Расчёты выполняются локально в браузере. Данные не отправляются автоматически.

| Раздел | Основная задача | Дополнительные сценарии |
| --- | --- | --- |
| 01 Состав тела | Navy, LBM, FFMI, ориентир по весу | Рекомпозиция: арифметический сценарий, не прогноз роста мышц |
| 02 Калории | QUICK/PRO, TDEE, БЖУ, калибровка | Диапазон белка |
| 03 Переедание | Энергетический сценарий, вода и гликоген | Существующая расширенная форма |
| 04 Восстановление | Личные сигналы, RHR/HRV baseline | Окно сна; устойчивые сигналы усталости без диагноза |
| 05 Прогресс | Дневник, тренд, плато, условный горизонт | Темп фазы; сравнение окружностей без второго дневника |
| 06 Силовые | e1RM, рабочие веса, история упражнения | Проценты/RIR; тоннаж нескольких разных подходов |
| 07 Конфигуратор штанги | Точный поиск доступного симметричного набора | Ближайший достижимый вес ниже цели |
| 08 Прогрессия нагрузки | Следующая сессия с учётом RIR, повторов, шага | Обязательное подтверждение сопоставимости условий |
| 09 Кофеин и сон | Остаток одной дозы при 3, 5 и 7 ч полувыведения | Наглядное сравнение предположений, без прогноза сна |

Отдельный каталог удалён. `recomposition`, `protein`, `phase`, `circumference`, `load`, `volume`, `sleep`, `fatigue` открываются внутри своего раздела. `cardio`, `adherence`, `friction`, `minimum`, `ifthen`, `review` больше не предлагаются как калькуляторы. Дневник соблюдения плана сохраняется в существующем daily check-in.

## Типы расчётов

- Опубликованные уравнения: Navy, FFMI, Mifflin, e1RM. Это оценки, а не прямые измерения.
- Точная арифметика: подбор блинов, тоннаж, время сна, сравнение введённых замеров.
- Сценарии: рекомпозиция, длительность фазы, экспоненциальный остаток кофеина. Допущения указаны рядом с результатом.
- Авторские эвристики: условия прогрессии и сигнал пересмотра нагрузки. Внешняя индивидуальная валидация не заявлена.

Прогрессия повышает вес только при подтверждённых сопоставимых упражнении, технике, амплитуде и отдыхе, двух сессиях на верхней границе повторов, RIR ≥2 и шаге ≤10%. Это практическое правило, а не обещание безопасности или роста силы.

Для объёма можно указать разные подходы: `8 x 60; 7 x 62.5; 6 x 65`. При заполнении этой строки считается сумма отдельных подходов; три прежних поля остаются для одинаковых подходов и совместимости. Тоннаж не измеряет гипертрофический стимул.

## Хранение и совместимость

Ключи localStorage и схема JSON не меняются. Старые результаты, история и избранное автоматически не удаляются. Архивные модели остаются в модуле ради импорта и чтения старых записей, но отсутствуют в навигации. QUICK/PRO, профиль, календарный дневник, экспорт, история и Personal OS сохраняют своих прежних владельцев.

Новые расчёты `progression` и `volume` имеют версию 2.1.0. Импорт снимков версии 2.0.0 использует прежние правила; старые записи не получают новую версию задним числом. Следующий новый расчёт выполняется по актуальной модели.
