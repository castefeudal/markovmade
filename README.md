# MARKOVMADE

Статический RU/EN сайт Павла Маркова с MARKOVMADE LAB, локальными расчётами, сохранением на устройстве и публикацией через GitHub Pages.

## Структура

```text
index.html                         Статическая оболочка, SEO и содержательные разделы
assets/css/tokens.css              Семантические дизайн-токены и палитры
assets/css/legacy.css              Стили, извлечённые из исходной страницы
assets/css/product.css             Состояния интерфейса и новые компоненты
assets/js/app-runtime.js           MARKOVMADE LAB, Personal OS и локальные сценарии
assets/js/i18n.js                  Словарь RU/EN и переключение языка
assets/js/theme-system.js          Obsidian, Ivory, Graphite и High Contrast
assets/js/hero-media.js            Адаптивное hero-видео и постер
assets/js/site-interactions.js     Навигация и взаимодействия страницы
assets/media/                      Локальные WebP изображения и hero-постер
assets/media/image-manifest.json   Размеры и пути локальных изображений
scripts/                           Оптимизация изображений
tests/                             Статическая и браузерная QA-проверка
```

Сайт остаётся статическим: сборщик и серверная часть не нужны. Страница постепенно разделяется на CSS/JS-модули, сохраняя прежние секции и калькуляторы.

## Локальный запуск

Нужен Node.js 20 или новее. Для E2E браузерной проверки нужен Chromium, доступный Playwright.

```sh
npm ci
npm test
npm run test:e2e
```

Откройте `index.html` напрямую или используйте любой статический HTTP-сервер. E2E-скрипт самостоятельно поднимает временный локальный сервер и сохраняет скриншоты в `test-results/`.

## Темы и язык

Темы меняют общие semantic tokens, сохраняются в `localStorage` и поддерживают системные настройки. Переключатель языка сохраняет выбор в браузере и локализует содержимое без перезагрузки. Проверяйте интерфейс с RU и EN: длина строк и переносы различаются.

## Калькуляторы

MARKOVMADE LAB состоит из независимых расчётных потоков для композиции тела, питания, переедания, восстановления, динамики прогресса и подбора стратегии. Расчёты работают в браузере; QUICK/PRO поля и прежние пользовательские сценарии сохраняются. В каждом сохранённом результате есть `modelVersion`, чтобы указать версию расчётной модели.

Это ориентировочные модели самонаблюдения, а не медицинская диагностика и не гарантия результата. При изменении формул обновляйте версию соответствующего потока и тестовые фикстуры.

## Доказательная база

В интерфейсе формулы обозначаются по их фактическому назначению (например, Mifflin–St Jeor для базовой оценки энергозатрат). Числовые результаты следует трактовать как оценки с неопределённостью и интерпретировать вместе с исходными данными, а не как диагноз. Не добавляйте медицинские утверждения, гарантии, отзывы или точность модели без проверяемого источника и соответствующего указания в интерфейсе.

## Данные и приватность

Профиль, история, сценарии и результаты сохраняются в `localStorage` на устройстве пользователя. Они не отправляются автоматически на сервер. Копирование, Telegram и внешние контакты открываются только после явного действия. Удаление данных сайта в браузере очищает локальное состояние.

## Изображения

Критичные изображения хранятся локально в `assets/media/portfolio/` и закодированы в WebP. Контентные изображения используют responsive `srcset`, `sizes`, `width` и `height`. Пути и размеры перечислены в `assets/media/image-manifest.json`. Для повторной оптимизации локальных изображений требуются `ffmpeg` и `ffprobe`:

```sh
npm run optimize:images
```

Постер hero хранится отдельно от видео. Видео загружается с `preload="metadata"`; reduced-motion и слабые устройства используют более лёгкий путь.

## Деплой

GitHub Pages публикует корневой `index.html` и папку `assets/` из production-ветки `main`. В репозитории должна быть включена публикация Pages из корня этой ветки. Production URL: <https://castefeudal.github.io/markovmade/>.

После публикации проверьте HTTP-ответ, `canonical`, локальные JS/CSS/изображения и переключение языка на production. Путь `/markovmade/` важен для GitHub Pages; не удаляйте его из asset URL.
