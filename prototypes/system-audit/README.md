# MARKOVMADE System Audit

Безопасный standalone-прототип lead magnet / diagnostic tool.

## Что делает
- задаёт 5 вопросов о ясности цели, трении старта, среде, обратной связи и возврате после сбоя;
- определяет самое слабое звено;
- выдаёт 7-дневный план и красный минимум;
- не просит контакт до выдачи результата;
- поддерживает `src` / `utm_source` для атрибуции.

## Как запустить
Открыть `index.html` локально в браузере.

## Граница
Это не medical/psychological diagnostic. Никаких production credentials и отправки данных наружу нет.
